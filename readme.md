# Python

## 格式化字串

### %

| 格式  | 說明     |
|:---:|--------|
| %s  | 字串     |
| %d  | 10進位整數 |
| %o  | 8進位    |
| %x  | 16進位   |
| %f  | 浮點數    |
|  +  | 靠右對齊   |
|  -  | 靠左對齊   |
| 數字  | 字串寬度   |
| .數字 | 小數點位數  |

### format()

| 格式  | 說明          |
|:---:|-------------|
|  :  | 設定格式前需要加上冒號 |
|  s  | 字串          |
|  d  | 10進位整數      |
|  o  | 8進位         |
|  x  | 16進位        |
|  f  | 浮點數         |
| \>  | 靠右對齊        |
|  <  | 靠左對齊        |
|  ^  | 置中對齊        |
| 數字  | 字串寬度        |
| .數字 | 小數點位數       |

### 跳脫字元

| 跳脫字元 | 說明  |
|:----:|-----|
|  \\  | 反引號 |
|  \'  | 單引號 |
|  \"  | 雙引號 |
|  \n  | 換行  |
|  \t  | 定位點 |

## 字串常用方法

| 方法           | 說明                |
|--------------|-------------------|
| len()        | 計算字串長度            |
| count()      | 計算字串內文字數量         |
| index()      | 取得字串索引值 若找不到會報錯   |
| find()       | 取得字串索引值 若找不到會回傳-1 |
| isalpha()    | 判斷字串是否為英文         |
| isdigit()    | 判斷字串是否為數字         |
| endswith()   | 判斷字串最後一個字母是否為指定字母 |
| startswith() | 判斷字串第一個字母是否為指定字母  |
| upper()      | 轉大寫               |
| lower()      | 轉小寫               |
| capitalize() | 首字大寫              |
| title()      | 單字大寫              |
| replace()    | 取代                |
| split()      | 轉串列               |
| strip()      | 去除前後空格或指定字元       |
| lstrip()     |                   |
| rstrip()     |                   |
