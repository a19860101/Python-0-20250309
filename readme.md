# Python

## 格式化字串

### %

| 格式  | 說明     |
|:---:|--------|
| %s  | 字串     |
| %d  | 10進位整數 |
| %o  | 8進位    |
| %x  | 16進位   |
| %f  | 浮點數    |
|  +  | 靠右對齊   |
|  -  | 靠左對齊   |
| 數字  | 字串寬度   |
| .數字 | 小數點位數  |

### format()

| 格式  | 說明          |
|:---:|-------------|
|  :  | 設定格式前需要加上冒號 |
|  s  | 字串          |
|  d  | 10進位整數      |
|  o  | 8進位         |
|  x  | 16進位        |
|  f  | 浮點數         |
| \>  | 靠右對齊        |
|  <  | 靠左對齊        |
|  ^  | 置中對齊        |
| 數字  | 字串寬度        |
| .數字 | 小數點位數       |

### 跳脫字元
| 跳脫字元 | 說明  |
|:----:|-----|
|  \\  | 反引號 |
|  \'  | 單引號 |
|  \"  | 雙引號 |
|  \n  | 換行  |
|  \t  | 定位點 |
